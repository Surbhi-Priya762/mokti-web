Power BI + SQL

Dashboards & data

Power BI dashboards and SQL analysis that turn store data into answers: what sells, where it goes and why it comes back.

Role
Analysis and dashboard design
Tools
Power BI, MySQL

The job

Store owners need quick answers: which products sell, which cities buy, which payment methods customers use, which orders are stuck and why products come back. Raw order exports don’t answer those questions on their own.

What I did

  • Built a Power BI sales dashboard from Storeily’s March 2025 orders
  • Built an inventory and dispatch tracker in Power BI as a practice project
  • Wrote SQL queries in MySQL to rank return reasons and the most-returned products
  • Analysed refund delays and how they relate to payment method

Features you can see

  • Sales dashboard: total revenue, orders, quantity sold and average order value
  • Top-selling products, a daily sales trend, the payment method split and sales by city, with a state filter
  • Inventory tracker: orders by status, revenue trend, warehouse performance for Mumbai, Bangalore and Delhi, and a low-stock alert that compares stock with the reorder level
  • SQL: return reasons ranked by count, and refund delay analysis

Built with

Power BI Desktop for the dashboards, MySQL Workbench for the SQL analysis.
